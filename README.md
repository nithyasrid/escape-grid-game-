# Escape the Grid — Update Pack

This update adds a visible HOW TO PLAY screen, in-game help, 3 hints per level, automatic stuck hints after 45 seconds, mobile controls, keyboard controls, and score penalties for hints.

## Deploy this update to the EXISTING Netlify site
1. Extract this ZIP.
2. Open the `escape-the-grid-v4` folder.
3. Keep `index.html` at the root and keep the `assets/` folder beside it.
4. In Netlify open your existing site → Deploys.
5. Drag the entire `escape-the-grid-v4` folder into the production deploy/drop area.
6. Wait for the deploy to finish, then open your same Netlify URL.

No new site is needed. The new production deploy replaces the old one.
